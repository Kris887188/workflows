# Моя книга / My Life Book (PWA)

Готовая стартовая версия личного приложения-книги жизни на **Next.js + TypeScript + Tailwind + Supabase**.

## Функции
- Логин/регистрация.
- Создание записей жизни (Life Entry).
- Ручной ввод текста.
- Загрузка файлов.
- Загрузка аудио (запись можно сделать стандартным диктофоном телефона и загрузить файл).
- Редактирование полей: заголовок, дата, люди, теги, заметки, фрагмент книги.
- Таймлайн записей.
- Поиск записей.
- Экспорт в Markdown.
- PWA-манифест для установки на телефон и десктоп.

## 1) Установка
```bash
npm install
cp .env.example .env.local
```

Заполните `.env.local`:
```env
NEXT_PUBLIC_SUPABASE_URL=...
NEXT_PUBLIC_SUPABASE_ANON_KEY=...
```

## 2) Настройка Supabase
1. Создайте проект на https://supabase.com
2. Откройте SQL Editor и выполните `sql/supabase_schema.sql`.
3. В разделе **Authentication** включите Email auth.
4. Скопируйте URL и anon key в `.env.local`.

## 3) Локальный запуск
```bash
npm run dev
```
Откройте http://localhost:3000

## 4) Деплой на Vercel
1. Запушьте проект в GitHub.
2. В Vercel: **New Project** -> импортируйте репозиторий.
3. Добавьте переменные окружения:
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`
4. Deploy.

## 5) PWA установка
### iPhone (Safari)
1. Откройте URL приложения в Safari.
2. Нажмите **Поделиться**.
3. Выберите **На экран «Домой»**.

### Android (Chrome)
1. Откройте приложение в Chrome.
2. Нажмите меню (⋮).
3. Выберите **Установить приложение** / **Add to Home screen**.

### Desktop (Chrome/Edge)
1. Откройте приложение.
2. Нажмите иконку установки в адресной строке.
3. Подтвердите установку.

## Важно
- Не используется SQLite; все данные, авторизация и файлы хранятся в Supabase.
- Чтобы добавить настоящую запись с микрофона внутри браузера, можно расширить компонент через MediaRecorder API в следующей версии.
